Este jogo têm como objetivo ser um primeiro aprendizado ao universo de desenvolvimento de jogos e seus conceitos específicos e gerais dos jogos. 
Até o momento este projeto é feito de forma independente, sem a intenção de lucro.

Um pouco sobre o jogo

O jogo baseia-se no sistema de jogos de estratégia, mais especificamente o Xadrez, mas com algumas mecânicas diferentes, que podem ser obtidas por diferentes meios, o jogo tem sistemas diferentes de jogabilidade que podem transitar entre o xadrez clássico até algo que não seja necessariamente Xadrez, mas algo divertido!
